# SGI Personal IRIS 4D/35 emulator

`emulator.ip12()` runs a big-endian R3000A in-process. It shares the R3000
interpreter with the Jazz machine and has its own PIC1 memory map, INT2
interrupt controller and timers, Z8530 serial port, RTC, Microwire EEPROM,
and WD33C93A SCSI controller with HPC1 descriptor DMA. It can attach a
512-byte-sector block device and run code from a PROM or a directly loaded
MIPS I executable.

Run the miniroot smoke from the Trex directory with the original IRIX 3.3 archive.

```sh
go run ./cmd/trex scripts/smoke/irix_ip12.star \
  IRIX_3.3_ARCHIVE.7z
```

The archive's **4D/35 support tape** contains the 3.3.2 IP12 miniroot. The
script reads the tape, EFS, and ECOFF directly. The EFS reader restores the
free tail to the filesystem's declared size after checking its allocation
bitmap. The miniroot goes at the beginning of partition 1. The kernel uses
that same partition for swap starting at block 30,000, so the partition
extends beyond both the EFS volume and that offset. Guest writes stay in a
memory overlay.

The smoke checks the version banner on the emulated serial port, actual
SCSI disk reads, and the original `/etc/init` text in user memory after
execution starts. The tested kernel identifies itself as **IRIX System V
Release 3.3.2 IP12 Version 03141619**.

The installed-system smoke reads selected EOE and 4D/35 software images
from the same archive and creates a big-endian EFS root and SGI partition
table in memory. It logs in through the serial console and checks the
guest's responses to `uname -a` and `id`. It uses the original miniroot
kernel with the installed userland and places swap on a separate
partition. The recipe declines the guest's automatic kernel relink
prompt.

```sh
go run ./cmd/trex scripts/smoke/irix_ip12_system.star \
  IRIX_3.3_ARCHIVE.7z
```

The desktop smoke starts the original 4Sight service on a fresh system
disk. It places four stock windows with the emulated mouse, then checks
the Calculator result of `2 + 3`, the Icon & Font Browser title and
SUNCORE glyph, and the ItemClass `DoIt!` button's notification. It also
types `uname -a` through the emulated keyboard in the NeWS terminal and
checks the rendered IRIX version. All four windows appear in one PNG.

```sh
go run ./cmd/trex scripts/smoke/irix_ip12_desktop.star \
  IRIX_3.3_ARCHIVE.7z \
  irix-4sight.png
```

```starlark
m = emulator.ip12(memory = 32 << 20)
m.attach_disk(1, disk)
m.load_executable(kernel, args = ["dksc(0,1,1)unix.IP12"],
                  env = ["console=d", "dbaud=9600", "rbaud=9600", "cpufreq=36"])
stop = m.run(20000000)
print(m.serial().read_available())
print(m.registers().pc)
m.close()
```

`m.break_at(address)` stops before an instruction. `m.read()` inspects
physical memory, while `m.read_effective()` uses the current CPU
translation. Both avoid device side effects. With `stop_on_exception=True`,
`m.run()` returns the exception and instruction at the point of origin.
`m.registers()` includes the WD33C93A register bytes and pending interrupt.

Direct loading supplies the pre-ARCS argument vectors and built-in
Ethernet-address, NVRAM-table, and console printf services. A supplied
PROM (`emulator.ip12(rom=...)`) executes from the reset vector.

The GR1 model executes HQ1 microcode from the host FIFO and includes
WEITEK arithmetic, RE2 spans and pixel transfers, XMAP palettes, and
BT431 cursor and BT457 palette ports. PIC1 graphics DMA carries context
state between guest RAM and the GE5. `m.graphics()` reports sequencer
and FIFO state and the cursor sprite origin. `m.screenshot()` captures
the 1280×1024 scanout as PNG. A register test exercises the FIFO through
the sequencer to rendered pixels. The emulated keyboard and mouse use
the on-board SCC ports. Use
`m.key_code(code, down=True)` and `m.mouse(dx, dy, buttons=0)` to send input.

GR1 command processing and scanout run on the host CPU in Go. IRIS GL
polygon rendering still has gaps, including a FIFO stall when the stock
Clock draws its face. Opening the Icon & Font Browser context menu can
also interrupt the 4Sight session. PROM-to-disk boot and later IRIX
releases remain unverified. DSP and Ethernet traffic require additional
device work.
